# 🏫 ARGS School POS

Complete School Management & POS System — Nursery to Matric.

## ✨ Features
- 🔐 Login (admin / admin123 — Settings me se change karein)
- 📊 Dashboard (stats + charts)
- 🎓 Students Enrollment
- ✅ Attendance (+ monthly summary)
- 🏆 Results & printable Report Cards (Grades A+ to F)
- 🧾 Fee Invoices (generate, mark paid, print)
- 💸 Expenses
- 👨‍🏫 Staff Management
- ⚙️ Settings (school info, fee structure, password)
- 💾 Backup & Restore (JSON export/import)

## 🚀 Live
Ye app GitHub Pages par live hai.

## 💡 Important
Data aap ke browser me (localStorage) save hota hai — har browser/device ka apna data hai.
Waqt waqt par **Backup page se JSON backup download** karein.
